# PharmaNear

بوابة ذكية للعثور على أقرب صيدلية عبر الـ GPS أو بالبحث باسم المنطقة.

## الهيكلية

```
pharmanear/
├── app.py              # خادم Flask: الصفحة الرئيسية + API الصيدليات
├── requirements.txt
├── vercel.json
├── .gitignore
├── templates/
│   └── index.html      # صفحة واحدة مكتفية ذاتياً (CSS + JS مدمجان بداخلها)
└── static/             # ملفات ثابتة (PDF وغيرها)
```

## المتطلبات

المشروع يعتمد على [SerpAPI](https://serpapi.com) لجلب بيانات الصيدليات من خرائط Google.
ستحتاج مفتاح API مجاني منهم.

> **تنبيه:** الباقة المجانية محدودة بحوالي 100 عملية بحث شهرياً، وكل ضغطة على زر
> البحث تستهلك عملية واحدة. راقب استهلاكك من لوحة تحكم SerpAPI.

## التشغيل محلياً

```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

export SERPAPI_KEY="ضع_مفتاحك_هنا"   # Windows: set SERPAPI_KEY=...
python app.py
```

ثم افتح http://127.0.0.1:5000

> خاصية الـ GPS في المتصفحات تعمل فقط عبر HTTPS أو على `localhost`.
> لن تعمل إذا فتحت الموقع عبر عنوان IP محلي مثل `192.168.x.x`.

## مفتاح الـ API

المفتاح يُقرأ من متغيرات البيئة **فقط** ولا يوجد أي مفتاح مكتوب داخل الكود،
حتى لا يتسرّب عبر سجل Git.

عند النشر على Vercel: اذهب إلى
`Project → Settings → Environment Variables` وأضف:

| المفتاح | القيمة |
|---------|--------|
| `SERPAPI_KEY` | مفتاحك من SerpAPI |

ثم أعد النشر (Redeploy) ليُطبَّق المتغير.

## نقاط الـ API

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | `/` | الصفحة الرئيسية |
| GET | `/api/pharmacies?lat=&lon=` | البحث بإحداثيات الـ GPS، مرتّبة من الأقرب للأبعد |
| GET | `/api/pharmacies?query=اسم_المنطقة` | البحث اليدوي باسم الحي أو الشارع |

### شكل الاستجابة

```json
{
  "status": "success",
  "count": 2,
  "data": [
    {
      "name": "صيدلية النور",
      "address": "شارع الرياض",
      "latitude": 15.585,
      "longitude": 32.535,
      "distance_meters": 771.2,
      "distance_text": "771 متر",
      "phone": "+249911000001",
      "status": "مفتوح"
    }
  ]
}
```

حقل `phone` يكون نصاً فارغاً `""` عندما لا يتوفر رقم — وعندها تعرض الواجهة
زر "مشاركة الموقع" بدلاً من زر اتصال معطّل.

### رموز الأخطاء

| الرمز | المعنى |
|------|--------|
| 400 | لم تُرسل إحداثيات ولا اسم منطقة |
| 500 | `SERPAPI_KEY` غير مضبوط على الخادم |
| 502 | خطأ من SerpAPI (مفتاح خاطئ أو انتهاء الحصة) أو فشل الاتصال |
| 504 | انتهت مهلة الاتصال بمزود البيانات |

## النشر على Vercel

```bash
vercel
```

ملف `vercel.json` يوجّه كل الطلبات إلى `app.py`، ويضمن عبر `includeFiles`
رفع مجلدي `templates/` و`static/` مع الدالة — وهذا ما يمنع مشكلة الشاشة
البيضاء الناتجة عن عدم عثور Flask على القوالب.

لا تنسَ ضبط `SERPAPI_KEY` في إعدادات المشروع قبل النشر.
